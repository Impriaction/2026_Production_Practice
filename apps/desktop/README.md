# apps/desktop - Desktop Client Placeholder

## Status

Placeholder directory for the future desktop client of ODPlatform.

## Planned Scope

- Provide a desktop-facing interaction layer for ODPlatform
- Reuse shared platform capabilities from `apps/platform`
- Serve as the local GUI entry for training, inference, and project management

## Why It Exists Now

This directory is created early as an architectural reservation so future work can be added without restructuring the repository.
